# Artificial Intelligence – Smart AI Assistant

## 📌 Project Description
The Smart AI Assistant is a simple web-based application designed to demonstrate the basic concept of Artificial Intelligence. It allows users to interact with a virtual assistant by entering questions and receiving predefined responses.

The project provides a beginner-friendly introduction to AI concepts and interactive web development.

## 🎯 Objectives
- To understand the basic concepts of Artificial Intelligence.
- To create an interactive virtual assistant.
- To provide automated responses to user questions.
- To improve knowledge of web development.

## ✨ Features
- Simple chatbot interface.
- User-friendly design.
- Interactive question and answer system.
- Automated responses.
- Real-time chat display.

## 🛠️ Technologies Used
- HTML – Structure of the application.
- CSS – Styling and design.
- JavaScript – Chatbot functionality.

## 🚀 How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Type a question in the chat box.
5. Click Send to receive a response.
